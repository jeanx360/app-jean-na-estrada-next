# Instalação — JNE App 2.1.1

1. Instalar sobre a branch limpa `release/2.1.0`.
2. Criar automaticamente a branch `release/2.1.1`.
3. Executar TypeScript, build e testes de rotas.
4. Criar uma chave gratuita na conta HeiGIT/openrouteservice.
5. Configurar `OPENROUTESERVICE_API_KEY` e `ROUTE_ESTIMATE_SECRET` no Preview da Vercel.
6. Fazer commit e push.
7. Validar autocomplete, localização, mapa, distância e duração no smartphone.

Não há migration nova.

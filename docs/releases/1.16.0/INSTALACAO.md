# Instalacao da JNE App 1.16.0

1. Partir da branch limpa `release/1.15.0`.
2. Executar o instalador do pacote.
3. Aplicar somente `supabase/migrations/1.16.0_driver_professional_finance.sql` no SQL Editor do Supabase.
4. Executar o teste automatizado incluido no pacote.
5. Fazer commit e push somente depois do build aprovado.

Nao execute o arquivo completo `supabase/schema.sql` em producao.

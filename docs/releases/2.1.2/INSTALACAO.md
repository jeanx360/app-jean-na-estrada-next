# Instalação 2.1.2

1. Aplicar o pacote sobre a branch limpa `release/2.1.1`.
2. O instalador cria a branch `release/2.1.2`.
3. Executar o script de testes do pacote.
4. Aplicar a migration no Supabase somente após os testes locais.
5. Fazer commit, push e validar o Preview com duas contas diferentes.

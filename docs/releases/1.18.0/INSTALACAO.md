# Instalação — JNE App 1.18.0

1. Comece na branch limpa `release/1.17.0`.
2. Execute o instalador incluído no pacote.
3. Execute apenas `supabase/migrations/1.18.0_driver_network_referrals.sql` no SQL Editor do Supabase.
4. Execute o teste automatizado.
5. Faça commit e push somente depois da aprovação do build e dos testes locais.

Não execute o arquivo `supabase/schema.sql` completo em produção.

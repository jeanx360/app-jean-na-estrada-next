# Instalação da JNE App 1.12.0

Base esperada: `release/1.11.1`, versão `1.11.1`, sem alterações pendentes.

O instalador cria `release/1.12.0` e aplica somente:

- `src/app/guia/page.tsx`
- `src/app/globals.css`
- `package.json`
- `package-lock.json`
- `public/sw.js`
- documentação da release

Esta versão não possui migration e não exige alteração no Supabase.

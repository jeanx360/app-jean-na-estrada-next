# Instalação — JNE App 1.17.0

1. Comece na branch limpa `release/1.16.0`.
2. Execute o instalador incluído no pacote.
3. Execute apenas `supabase/migrations/1.17.0_account_plans.sql` no SQL Editor do Supabase.
4. Execute o teste automatizado.
5. Faça commit e push somente após o build ser aprovado.

Não execute o arquivo `supabase/schema.sql` completo em produção.

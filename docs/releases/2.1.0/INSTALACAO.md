# Instalação — JNE App 2.1.0

1. Instale o pacote na base limpa `release/2.0.2`.
2. Execute os testes locais.
3. Aplique a migration `2.1.0_driver_smart_routes_reminders.sql` no Supabase.
4. Configure as variáveis de mapas no Preview.
5. Faça commit e push da branch `release/2.1.0`.
6. Valide o Preview no smartphone antes da produção.

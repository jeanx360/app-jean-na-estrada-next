# JNE App 1.7.3 — Acessos rápidos do motorista

## Objetivo

Deixar as quatro ações mais usadas pelo motorista disponíveis no topo do painel, com boa leitura e pouco espaço ocupado no celular.

## Alterações

- substituição dos dois botões antigos do bloco “Pronto para o próximo serviço?” por quatro acessos rápidos;
- botão **QR de divulgação**, direcionando para o cartão ou para a configuração do perfil quando necessário;
- botão **Calcular viagem**;
- botão **Agendamentos**, direcionando para a Central de Reservas;
- indicador numérico no botão de agendamentos quando existem novas reservas;
- botão **Home do JNE**, usando `/?modo=conteudo` para evitar o redirecionamento automático de volta ao painel do motorista;
- layout em uma linha nas telas maiores;
- layout compacto 2 × 2 em telas de até 720 px;
- ícones centralizados, áreas de toque adequadas e destaque visual no QR de divulgação;
- atualização da versão e do cache PWA para 1.7.3.

## Banco de dados

Não existe migration SQL nesta etapa.

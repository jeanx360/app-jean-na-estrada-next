# Checklist rápido da Comunidade VIP

- [ ] A migração 1.4.0 executou sem erro.
- [ ] Administrador entra em `/admin/comunidade`.
- [ ] VIP entra em `/comunidade`.
- [ ] Membro comum é redirecionado para `/assinar`.
- [ ] Publicação simples é criada.
- [ ] Imagem válida é enviada e exibida.
- [ ] Arquivo acima de 5 MB é recusado.
- [ ] Enquete aceita de 2 a 6 opções.
- [ ] Um usuário não consegue votar duas vezes na mesma enquete.
- [ ] Curtidas funcionam em post e comentário.
- [ ] Comentário e resposta geram interação.
- [ ] Publicação bloqueada não aceita novos comentários nem votos.
- [ ] Denúncia aparece no painel administrativo.
- [ ] Restrição de postagem funciona.
- [ ] Restrição de comentário funciona.
- [ ] Administrador não é rebaixado após novo aceite legal.
- [ ] Busca global encontra publicação apenas para VIP/admin.
- [ ] Layout funciona em 360 px, 390 px, 430 px e desktop.

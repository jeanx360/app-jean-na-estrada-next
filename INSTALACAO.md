# Instalação — JNE App 1.5.0

1. Extraia o pacote na raiz do projeto e confirme as substituições.
2. Execute `supabase/migrations/1.5.0_professional_driver.sql` no SQL Editor do Supabase.
3. Rode `npm version 1.5.0 --no-git-tag-version`.
4. Apague `.next` e execute `npm run build`.
5. Teste `/perfil`, `/motorista`, `/motorista/calculadora`, `/motorista/orcamentos`, `/motorista/configuracoes` e `/`.
